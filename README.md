# Lulus Studio

Website portofolio fotografer wisuda berbasis HTML, CSS, dan JavaScript murni. Tidak memerlukan proses build atau instalasi dependensi.

## Struktur

```text
galerywisuda/
|-- index.html
|-- README.md
|-- css/
|   `-- style.css
`-- js/
    `-- main.js
```

## Menjalankan

Buka `index.html` langsung di browser. Foto portofolio dan font saat ini dimuat dari Unsplash dan Google Fonts, jadi koneksi internet diperlukan untuk menampilkannya.

## Kustomisasi

- Ubah konten, judul foto, dan tautan di `index.html`.
- Atur warna, tipografi, dan tata letak di `css/style.css`.
- Atur filter galeri, lightbox, dan navigasi seluler di `js/main.js`.
- Ganti nomor WhatsApp contoh `6281234567890` dan tautan Instagram dengan akun fotografer.
- Untuk foto milik sendiri, simpan gambar di folder `assets/images/`, lalu ganti URL gambar di `index.html` dengan path lokal.
